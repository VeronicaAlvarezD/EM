# Sitio Web de Ciberseguridad

Este es un sitio web informativo y educativo sobre **ciberseguridad**, desarrollado como parte de un curso de Fullstack con Python. El sitio contiene tres secciones principales:

---

## 📄 Páginas del Sitio

1. **Inicio**  
   - Explicación básica de qué es la ciberseguridad.  
   - Imagen destacada y navegación entre secciones.

2. **Amenazas Comunes**  
   - Descripción de ataques como phishing, ransomware, malware y DDoS.  
   - Tarjetas interactivas y un acordeón con ejemplos reales.

3. **Consejos de Seguridad**  
   - Lista de buenas prácticas para protegerte en línea.  
   - Formulario de contacto con validación en JavaScript.  
   - Modal con un test interactivo básico de seguridad.

---

## 🛠 Tecnologías Utilizadas

- HTML5 y CSS3
- Bootstrap 5
- JavaScript y jQuery
- Git y GitHub
